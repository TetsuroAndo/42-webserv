# Startup チェックリスト

- [ ] 引数付き起動: 指定設定で起動し、指定ポートでLISTEN
- [ ] デフォルトパス起動: 引数なし起動でデフォルト設定を読込
- [ ] 複数ポート起動: すべてのlistenポートでLISTEN
- [ ] 複数serverブロック: すべてのサーバーがLISTEN
- [ ] 設定ファイル不在で非0終了
- [ ] 設定ファイル権限不足で非0終了
- [ ] 不正キー(server/location/listen/log)で非0終了
- [ ] 不正値(portに数値以外、未知メソッド)で非0終了
- [ ] ポート重複(同一config/他プロセス占有)で非0終了
