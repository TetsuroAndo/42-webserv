# Timeout and Keep-Alive チェックリスト

## タイムアウト処理

### リクエストヘッダータイムアウト (requestHeaderTimeoutSec)
- [ ] リクエストライン送信後、ヘッダー受信前にタイムアウト発生で切断
- [ ] タイムアウト時間は設定値に従う

### リクエストボディータイムアウト (requestBodyTimeoutSec)
- [ ] ボディー受信途中でタイムアウト発生で切断
- [ ] タイムアウト時間は設定値に従う

### Keep-Alive接続のアイドルタイムアウト (timeoutSec)
- [ ] リクエスト完了後、次回リクエスト待ちでタイムアウト発生で切断
- [ ] タイムアウト時間は設定値に従う

### 複合シナリオ
- [ ] POSTリクエストのボディー転送が非常に遅い場合のタイムアウト
- [ ] CGI実行中に別クライアントからのリクエストがブロックされない

## キープアライブ処理

### 基本的なKeep-Alive動作
- [ ] HTTP/1.1デフォルトでKeep-Alive接続を維持
- [ ] 同一接続で複数のリクエストが処理可能
- [ ] 各リクエスト後に適切にコンテキストがリセットされる

### Connection ヘッダー処理
- [ ] `Connection: close` 受信時は接続を閉じる
- [ ] `Connection: keep-alive` 受信時は接続を維持
- [ ] レスポンスに `Connection: close` を含める（必要時）

### Keep-Alive時のエラーハンドリング
- [ ] 処理エラー発生後も接続が適切にリセットされる
- [ ] 404などのエラーレスポンス後にKeep-Aliveが継続される

### 負荷テスト
- [ ] 長時間のキープアライブ接続でメモリリークが発生しない
- [ ] 複数のクライアントが同時にKeep-Alive接続を維持できる
